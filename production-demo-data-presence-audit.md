- **Demo data detected:** YES (for Business ID 1: "Acme Corp") / NO (for Businesses ID 2, 3, 4: "bhoomika" workspaces)

- **Automated Cleanup Safety:** YES, cleanup can be safely automated for specific test/demo workspaces or explicit sample record IDs, provided real user workspaces remain completely untouched.

### Evidence Breakdown

3. **Schema Markers:** The persistent tables (`customers`, `products`, `transactions`, `expenses`) do not have an explicit `is_demo` or `source` column. Therefore, demo data is identified structurally by association with the test workspace ("Acme Corp", ID 1).
